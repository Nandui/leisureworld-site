# LeisureWorld polish — 16 September 2026

This pass refines the existing site. It retains the approved homepage wording,
Archivo typography, navy identity, photographs, iPhone artwork and app-first
booking flow. Product context updates in `PRODUCT.md` belong to the preceding
initialization task.

## Changes

- Shared desktop alignment now uses one maximum content width. At a 1920px
  viewport, hero text previously began at 72px while content began at 232.5px.
  Header branding, hero text and content now all begin at 232.5px.
- Swim School and editorial programme breadcrumbs no longer inherit an extra
  35px bottom margin from the shared accessibility stylesheet.
- Footer links and headings, gym filters, class counts and timetable guidance
  use a readable 14px size. Existing touch-target heights remain intact.
- Existing current-page navigation markers now have visible styling. A stable
  scrollbar gutter prevents the page from shifting when the menu opens.
- Supporting-page headings balance their lines. Policy paragraphs have a
  bounded reading measure; price figures use tabular numerals.
- Section jumps and timetable actions use their container's gap instead of
  adding an unrelated inline-link margin.
- All 48 pages reference the updated stylesheet cache keys. Generator-only
  changes to entity escaping and attribute ordering were removed from source.
